Welcome to our Referral Program!

Refer others to earn points. The top 5 users with the most points will receive exclusive incentives. Follow the guide below to learn more about how the referral system works.

## Referral Program Guide

Check out the Referral Program Guide below to see how it all works.

### Steps

Follow the steps below to get your referral link and how to use it.

1. Go to [bit10.app/referral](https://www.bit10.app/referral) or [testnet.bit10.app/referral](https://testnet.bit10.app/referral) and connect your Plug wallet. Then click on **'Copy your referral link'** to copy your unique link.

<Callout>**Note:** You need to connect to the ICP chain to copy and share your referral.</Callout>

### Duration

The Referral Program will start and end on the following dates. Referrals and tasks completed **only during this period** will be counted:

- **Start Date**: 16 June, 2025 - 00:00 AM IST (GMT +5:30)  
- **End Date**: 28 June, 2025 - 00:00 AM IST (GMT +5:30)

### Instruction

- Points and leaderboard update every 5 minutes.
- Only successful transactions count.
- You get points for each task only once.
- The **first** person whose referral link is used gets the points when a transaction is completed.
  *Example:* If User C uses Person A's referral link and completes a transaction, Person A gets the points - even if C later uses Person B's referral link.
- If no transaction is done with the first referral link, and a transaction happens using another valid referral link, that second person will get the points.

### FAQs

<Accordions>
  <Accordion title='Who can I refer?' id='1'>
    You can refer anyone who hasn't connected their wallet on the platform yet using your referral link.
  </Accordion>

  <Accordion title='How do I earn referral points?' id='2'>
    You earn points when your referred users complete tasks or transactions. Points vary depending on the type of activity. See the [Points section](referral#points) for more details.
  </Accordion>

  <Accordion title="Will I get points if someone uses my referral link but doesn't make any transaction?" id='3'>
    No, you only get points when your referral successfully completes a task or transaction.
  </Accordion>

   <Accordion title='What if a user uses multiple referral links?' id='4'>
    Points go to the first valid referral link used that leads to a successful transaction. If no transaction is made, the next valid link that results in a transaction will get the points.
  </Accordion>

  <Accordion title='How often is the leaderboard and points updated?' id='5'>
    The leaderboard and points updates every 5 minutes with the latest points and rankings.
  </Accordion>

  <Accordion title='Where can I track my referral stats?' id='6'>
    You can view your stats like points earned, tasks completed, and incentives from the **Profile** tab on the Referral page.
  </Accordion>
</Accordions>
