Here is a guide to connecting your wallet on different chains. The next few pages will guide you through setting up and using the BIT10 testnet.

<Callout>Note: On the testnet, you can currently buy the Test BIT10 token and transfer it between individuals. However, you cannot swap it for another crypto token.</Callout>

<p align='center'>

We are using the Plug wallet as our primary wallet for the testnet. You can install the Plug wallet extension in your browser by visiting [plugwallet.ooo](https://plugwallet.ooo).

### Setting Up Plug Wallet

After installing the Plug wallet extension, open it. Here are some key terms:
1. <b>Principal ID</b>: This is your unique wallet identifier generated for each wallet.
2. <b>Account ID</b>: This is derived from the Principal ID and is used in the ICP and NFT registries to identify the owners of ICP and NFTs.
3. <b>Manage</b>: Click this button to select the tokens you want to display in your wallet.

<p align='center'>
<ImageZoom src='https://raw.githubusercontent.com/ZeyaRabani/Gitbook2/main/public/assets/part_3/testnet/install_plug.png' alt='Install Wallet' className='rounded border w-3/4 md:w-1/3' align='center' width={802} height={1404} />
</p>

### Obtaining BIT10.BTC Tokens

You can visit [testnet.bit10.app/faucet](https://testnet.bit10.app/faucet) to request BIT10.BTC tokens. Users need to enter their email and the Principal ID of their wallet. BIT10.BTC is a test token with the same value as testnet BTC.
