## What is the BIT10 SOL Utility Token?

The Utility Token is not the BIT10 SOL Index Fund itself.

It does not represent ownership of the index or the underlying Solana tokens. Instead, it is the on-chain utility layer that connects the community to the live BIT10 SOL Index Fund and  future products and utilities tied back to the Index Fund. It was created to:

- Validate real demand before full commitment
- Let early supporters shape what gets built
- Align the community with BIT10’s long-term success on Solana

Today it delivers real, revenue-linked utility for everyone who bought the BIT10 SOL Utility Token Launched on EasyA Kickstarter.

## Detailed Token Utilities 

The BIT10 SOL Utility Token now has four concrete, revenue-generating utilities directly linked to the BIT10 SOL Index Fund:

1. Buy the Index Fund with Utility Token

Users can purchase the BIT10 SOL Index Fund token directly using BIT10 SOL Utility Token (in addition to SOL or stablecoins). This creates immediate product-level demand for the utility token.

2. Revenue Buybacks (50% of fees)

50% of every 0.5% fee collected on BIT10 SOL Index Fund buys and sells is automatically used to buy back BIT10 SOL Utility Tokens from the open market. This puts real buying pressure behind the token every single time the index is used.

3. Pay for Pro Subscriptions

Holders can pay for BIT10 Pro subscriptions (lower fees + cashback rewards) using the Utility Token. This creates monthly recurring demand directly tied to the token.

4. Monthly Airdrops to Top Holders

Every month, 10% of total 0.5% fees collected from the Index Fund is used to buy BIT10 SOL Index Fund tokens. These tokens are then airdropped proportionally to the top 10 holders of the BIT10 SOL Utility Token.
